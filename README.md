# ISAAC AUTO - Automotive Dealership Website

A modern, responsive automotive dealership website for ISAAC AUTO, a premium car dealership based in Casablanca, Morocco. The site showcases luxury vehicles with a sleek design using the brand's signature colors.

## Features

- Responsive design that works on mobile, tablet, and desktop
- Dark/light mode toggle with localStorage persistence
- Vehicle listings with filtering capabilities
- Detailed vehicle pages with image galleries
- Contact page with Google Maps integration
- About page with company information

## Technologies Used

- React with TypeScript
- React Router for navigation
- CSS Modules for styling
- Lucide React for icons

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Start the development server: `npm start`
4. Build for production: `npm run build`

## Deployment

This site is deployed on Netlify. Any changes pushed to the main branch will automatically trigger a new build and deployment.

## Color Scheme

- Primary: Dark Gray (#4d4d4d)
- Secondary: Light Gray (#a7a7a7)
- Accent: Purple (#8A2BE2)
- Neon Effects: Purple (#8A2BE2) and Bright Cyan (#00BFFF)
